## Objetivo

Demonstração prática de conceitos Git e GitHub: repositório local, commits, branches, merge com conflito, tags e versionamento.

## Como executar localmente

```powershell
python -m http.server 8000
```

Abrir: http://localhost:8000/index.html

## Estrutura do projeto

- `index.html` — Página principal
- `styles.css` — Estilos CSS
- `script.js` — JavaScript
- `reports/` — Evidências e relatório

## Fluxo demonstrado

1. Commits incrementais (criação de ficheiros, alterações, etc.)
2. Branches: `feature/alunoA` e `feature/alunoB`
3. Conflito intencional e resolução manual
4. Tags: v1.0.0, v1.1.0
5. Histórico completo em git log
